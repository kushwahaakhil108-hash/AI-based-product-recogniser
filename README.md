# AI-based-product-recogniser
"AI Based Product Recogniser is a machine learning project built with Google Teachable Machine. It uses a custom-trained image classification model that learns to identify products from example photos, without writing any neural network code. Users can train the model through Teachable Machine's visual interface, export it, and run real-time recognition from a webcam or uploaded images directly in the browser. The project demonstrates how transfer learning makes practical image recognition accessible to anyone, and works well as a foundation for retail, inventory, or educational applications. The trained model is publicly hosted on Teachable Machine's platform."
